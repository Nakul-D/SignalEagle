# SignalEagle
A feedback aggregation platform that collects data from multiple sources (email, Twitter, etc.) and uses an LLM to generate concise summaries and actionable insights.

## **Project Setup**

### Prerequisites
- AWS account
- AWS CLI (installed and configured)
- Docker
- WSL (only on Windows)

> All environments use Docker and AWS CLI. No other dependencies are required.

### Development/Testing environment

**Steps**:
- Change directory into `cd /setup/dev`
- Run bash script
  - On Linux and macOS run `./main.sh`
  - On Windows you need WSL. Run `wsl ./main.sh`
